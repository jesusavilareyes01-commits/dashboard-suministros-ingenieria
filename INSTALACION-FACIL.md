# 🚀 INSTALACIÓN SÚPER FÁCIL

## Opción 1: Instalación Automática (Recomendada)

### Requisitos:
- Tener Node.js instalado (descargar de: https://nodejs.org)

### Pasos:
1. Abrir terminal/CMD en la carpeta del proyecto
2. Ejecutar: `npm run install-all`
3. Ejecutar: `cd client && npm start`

¡Listo! Tu dashboard estará en: http://localhost:3000

## Opción 2: Con Docker (Más fácil)

### Requisitos:
- Tener Docker instalado (descargar de: https://docker.com)

### Pasos:
1. Abrir terminal/CMD en la carpeta del proyecto
2. Ejecutar: `docker-compose up -d`

¡Listo! Tu dashboard estará en: http://localhost:3000

## ✅ ¿Funcionando?
- Frontend: http://localhost:3000
- Backend: http://localhost:5000
